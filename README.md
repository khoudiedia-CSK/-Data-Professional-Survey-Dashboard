# -Data-Professional-Survey-Dashboard
📌 Description du projet  Ce projet a été réalisé avec Microsoft Power BI dans le but d’analyser les données d’un sondage réalisé auprès de professionnels de la data.
Le dashboard permet d’explorer différents aspects du métier de la data tels que :

les rôles professionnels les plus fréquents,
les secteurs d’activité,
les langages de programmation préférés,
la répartition géographique des répondants,
ainsi que plusieurs indicateurs clés liés aux carrières dans la data.
🎯 Objectifs du projet
Analyser les tendances du marché de la Data
Identifier les profils professionnels les plus représentés
Étudier les préférences technologiques des répondants
Visualiser les données de manière interactive et intuitive
Développer des compétences en data visualisation avec Microsoft Power BI
🛠️ Technologies utilisées
Microsoft Power BI
Power Query
DAX
Dataset : Data Professional Survey
